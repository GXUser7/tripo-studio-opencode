# Tripo Studio для OpenCode

Неофициальный адаптер [GrinZero/tripo-studio-plugin](https://github.com/GrinZero/tripo-studio-plugin) для **OpenCode V2 на Windows**. Позволяет использовать свой аккаунт Tripo Studio без отдельного API-ключа. Облачные операции расходуют кредиты Studio — «без API-ключа» не означает «бесплатно».

## Авторство

- **GrinZero и контрибьюторы tripo-studio-plugin** — исходный MCP-сервер, операции генерации и обработки, исходные инструкции. Исходный проект распространяется по MIT; уведомления сохранены в [UPSTREAM-LICENSE](UPSTREAM-LICENSE).
- **[GXUser7](https://github.com/GXUser7)** — инициатор адаптации, владелец репозитория и участник ручной проверки входа.
- **Claude (Anthropic)** — ИИ-соавтор кода адаптера, тестов, интеграции и документации. Соавторство также отмечено трейлером `Co-authored-by` в коммитах, созданных с его участием. Это не официальный продукт или одобрение Anthropic, Tripo либо OpenCode.

Пакет upstream устанавливается как зависимость, а не копируется целиком. Версия намеренно зафиксирована на **0.3.13**: защита от фонового чтения браузерных хранилищ требует пересмотра при обновлении.

## Что добавлено

- Обычный MCP stdio-прокси, совместимый с OpenCode.
- Явный ручной вход в отдельном окне Microsoft Edge с отдельным профилем.
- Изоляция сессии адаптера от существующих данных upstream.
- Отключение фонового поиска cookies в основных браузерах.
- Скрытие внутренней передачи cookie из MCP-ответов и диагностик.
- Тесты корреляции запросов, отмены, обработки ошибок и браузерного жизненного цикла.
- Русскоязычный [skill](skills/tripo-studio/SKILL.md) с ограничениями OpenCode.

## Требования

- Windows, **Node.js 24+**, npm и установленный Microsoft Edge.
- OpenCode V2.
- Свой аккаунт [Tripo Studio](https://studio.tripo3d.ai/).
- Blender опционален: для локальных операций с мешем и рендеринга.

Другие ОС не проверены; текущая реализация требует `LOCALAPPDATA` и запускает канал `msedge`.

## Установка

```powershell
git clone https://github.com/GXUser7/tripo-studio-opencode.git
cd tripo-studio-opencode
npm.cmd ci --ignore-scripts
npm.cmd test
```

Добавьте запись из [opencode.example.json](opencode.example.json) в существующий `~/.config/opencode/opencode.json`. Замените `C:/PATH/TO/tripo-studio-opencode/adapter/main.mjs` абсолютным путём вашего клона. **Не заменяйте весь личный конфиг примером**: сохраните настройки провайдеров и остальные серверы.

Скопируйте навык:

```powershell
New-Item -ItemType Directory -Force "$HOME\.config\opencode\skills" | Out-Null
Copy-Item -Recurse .\skills\tripo-studio "$HOME\.config\opencode\skills\"
```

OpenCode подхватывает изменения автоматически; при необходимости используйте `/reload` или `/mcps`.

## Вход и использование

Попросите агента:

> Загрузи навык tripo-studio, проверь авторизацию. Если нужно, запусти вход через отдельное окно Edge. Пока не выполняй платных операций.

Только явный вызов `tripo_auth_login` открывает окно. Войдите вручную на официальном сайте. После проверки сессии окно закроется — это нормально. Пароли, коды, cookies и токены **не нужно передавать в чат**.

Проверить подключение можно бесплатными чтениями `tripo_auth_status`, `tripo_get_payment`, `tripo_list_models`. В Code Mode имена имеют вид `tools.tripo.tripo_auth_status()`; инструменты нужно находить через каталог OpenCode.

## Важное: UI и списание кредитов

Это **не перенос графического интерфейса Codex**. MCP Apps workbench и интерактивные карточки здесь не реализованы. Пример конфига блокирует 7 UI/app-only инструментов; из 68 зарегистрированных upstream доступны 61.

Создающие инструменты upstream запускают **серверный таймер на 60 секунд**, после которого задача может отправиться и списать кредиты **без видимой карточки и дополнительного клика**. Сначала согласуйте параметры, стоимость и бюджет, затем вызывайте создание. Для ожидания используется `tripo_get_configuration_review`, затем `tripo_task_wait` и `tripo_download`. Не создавайте повторную задачу, если исход неизвестен.

## Хранение и безопасность

- Профиль: `%LOCALAPPDATA%\TripoStudioPlugin\opencode-browser`.
- Сессия и задачи: `%LOCALAPPDATA%\TripoStudioPlugin\opencode-session`.
- Результаты по умолчанию: `~/Documents/TripoStudio`.

Эти данные чувствительны: не коммитьте и не отправляйте их в issues. ACL ограничивает доступ, но это **не шифрование от пользователя Windows или администратора**. Выход из MCP очищает сессию upstream, но не вход в отдельном профиле Edge.

Подробности протокола, очистки и защиты — [adapter/README.md](adapter/README.md). Исходный `tripo_auth_import` остаётся доступен по протоколу; инструкция агенту запрещает просить секреты или вызывать его вручную.

## Проверки и границы

```powershell
npm.cmd test
npm.cmd run smoke
```

При первоначальной проверке: 8 тестов прошли; ручной вход на Windows, проверка авторизации, чтение баланса и списка моделей прошли. **Генерация, списание кредитов, экспорт и скачивание в этой адаптации ещё не проверены end-to-end.** Smoke-тест не открывает браузер и не выполняет платных операций.

Интеграция использует неофициальные веб-интерфейсы Studio через upstream. Изменения сайта могут её сломать. Ограничения SSO не обходятся. Не обновляйте upstream вслепую: guard завершает запуск при несовпадении версии или маркера.
